## 개발부터 출시까지 모든 과정을 경험해본
클라이언트 프로그래머 장서윤입니다.<br>

[[English]](https://github.com/yogurt-31/yogurt-31/blob/main/README_en.md)

<br>

저는 게임 콘텐츠와 유저를 최단 거리로 연결할 수 있는 개발자입니다.<br>
유저에게 즐거움을 제공하기 위해 적극적으로 소통하며, 피드백을 통해 끊임없이 콘텐츠를 개선해 왔습니다.<br>
앞으로도 새로운 도전을 펼치는 길에서, 제 강점을 바탕으로 유저와 함께 만들어가는 미래를 실현할 준비가 되어 있습니다.<br>

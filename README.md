[[English]](https://github.com/yogurt-31/yogurt-31/blob/main/README_en.md)

<br>

저는 개발 역량과 더불어 아트와 기획 지식까지 갖춰 팀원들과의 협업 역량을 키웠으며,<br>
유저에게 즐거움을 제공하기 위해 적극적으로 소통하여 끊임없이 콘텐츠를 개선해 왔습니다.<br>
앞으로도 새로운 도전을 펼치는 길에서, 유저들에게 **최고의 경험을 선사하는 게임**을 만들어 가고 싶습니다.<br>

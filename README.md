## 개발부터 출시까지 모든 과정을 경험해본
클라이언트 프로그래머 장서윤입니다.<br>

[[English]](https://github.com/yogurt-31/yogurt-31/blob/main/README_en.md)

<br>

저는 개발 역량과 더불어 아트와 기획 지식까지 갖춰 팀원들과의 협업 역량을 키웠고,<br>
유저에게 즐거움을 제공하기 위해 적극적으로 소통하며 끊임없이 콘텐츠를 개선해 왔습니다.<br>
앞으로도 새로운 도전을 펼치는 길에서, 유저들에게 최고의 경험을 선사하는 게임을 만들어 가고 싶습니다.<br>
